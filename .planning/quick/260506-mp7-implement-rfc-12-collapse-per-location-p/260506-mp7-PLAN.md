**Implementation rules:**
1. **Copy logic verbatim from source.** Do not "improve" timings, easing, or thresholds. Visual parity is the contract.
2. **Tolerant DOM-missing guards:** every widget function must early-return if its required element is absent (current pattern). The widget set is a superset; not every page has every element.
3. **`prefers-reduced-motion` is honored in two places:** initTilt (no-op mousemove) and initHeroVideo (skip autoplay). Preserve both.
4. **Game popup default off:** `enabled` parameter defaults false; the `setTimeout(showGamePopup, 8000)` line stays commented out in source. Handlers still attach so future re-enable is one line.
5. **No ES module syntax** (`import`/`export`). Plain script, IIFE wrapping. The file ships as `<script defer src="/js/page-widgets.js?v=1">`.
6. **No new browser globals beyond `window.TMPage` and the existing `window.updateEyebrowLocation`.**
