# Off-Site GEO Authority Brief

Use this brief when creating or updating third-party profiles, press pitches, video descriptions, directory submissions, or community answers. The goal is entity consistency: every reputable off-site mention should describe Time Mission with the same public facts that appear on the website.

## Canonical Entity Description

Time Mission is a team-based interactive mission-room entertainment venue where teams of 2 to 5 players complete 25+ short mission rooms in 60, 90, or 120 minute sessions. Each mission lasts about 1 to 5 minutes and can test speed, strength, skill, memory, logic, teamwork, or coordination. Time Mission is designed for families, friends, birthday parties, corporate team building, school field trips, private events, date nights, and group outings.

## Profile Consistency Checklist

- Name: Time Mission
- Website: https://timemission.com
- Category: indoor entertainment, challenge rooms, team-based experiential entertainment
- Primary description: use the canonical entity description above or a shortened version that keeps team size, mission count, session lengths, and use cases intact.
- Location references: link to https://timemission.com/locations for the current open/coming-soon roster instead of hard-coding expansion claims.
- Pricing references: link to https://timemission.com/pricing.md or the relevant live checkout page; do not quote a universal ticket price.
- Social/entity links: use only verified profiles already listed in `src/data/site/seo-organization.json` unless a new profile has been confirmed.
